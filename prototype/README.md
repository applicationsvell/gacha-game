# 試作

企画提案書(`../docs/PROPOSAL.md`)の試作です。

- ① ガチャ・経済・戦闘のロジックと自動テスト
- ② パック開封の画面と演出
- ③ 遠征とオートバトルの画面

店の画面はまだありません。遠征で稼ぐほかに、試作用のボタンでもゴールドを補充できます。

## 動かし方

Node.js 22.18 以上が必要です(TypeScript をそのまま実行します)。

```
npm install      # TypeScript と Vite が入る
npm run dev      # 開発サーバー。表示された URL をブラウザで開く
npm run build    # dist/ に書き出す(相対パスなので、どこに置いても開ける)
npm test         # 自動テスト
npm run check    # 型チェックとテスト
```

## 開封の演出(提案書 4.5節)

| 場面 | 内容 |
|---|---|
| 封を切る | パックの上端を指でなぞると切れる(ボタンでも開けられる)。切り口から漏れる光の色が、中の最高レア度の予告になる(白・青・紫・金・虹) |
| めくる | 1枚ずつめくる。レア枠は最後。SR 以上の前は画面が暗くなり、カードが震え、心音が鳴る |
| 昇格 | SR 以上のパックの25%では、最後の1枚の直前に光の色が1段上がる。実際より高く見せることはしない |
| SR / SSR | 閃光、衝撃波、火花、画面の揺れ、文字の判押し。SSR は回転する光線と紙吹雪 |
| UR | 約15秒の専用演出。暗転、封印の紋章にひびが入って砕け、虹の光線の中にカードが降りてくる |
| 仕上げ | ホロは指の位置で虹色の光が動く。フルアートは絵が全面に広がる。ゴールドは金箔と光の粒 |
| ゴッドパック | 封を切った時点で虹の光と「GOD PACK!!」 |
| 10パック | ボックスを開け、50枚を並べて C〜R を一気にめくり、SR 以上は1枚ずつ大きく見せる |
| 結果 | NEW、★まであと何枚、相場価格、合計額 |

## 遠征(提案書 5.1節、6.1節)

| 場面 | 内容 |
|---|---|
| 準備 | 行き先(芽吹きの森、鉄錆の坑道)と編成5体を選ぶ。同じ種族の連携ボーナスと強さの目安が出る。おまかせ編成あり |
| 地図 | 7層。各層で2〜3本の道(戦闘、強敵、宝、出来事、野営地、ボス)から1つ選ぶ。敵の顔ぶれ、報酬、強さの目安(余裕・互角・危険)が見える |
| 戦闘 | オートバトルを再生する。先頭どうしの攻撃、ダメージの数字、能力の発動、退場、分身の出現。×1・×2・×4、結果へ飛ばすこともできる |
| 野営地 | ドロップパック(地域の種族だけ・3枚)を開けて、出たカードをすぐ編成に入れられる。「帰る」か「奥へ進む」かを選ぶ |
| 精算 | 負けると戦利品の半分を失う。カードは失わない。森のボスを倒すと坑道が開く |

難しさの目安(シミュレーションで確認): 最初の5パックで組んだ編成で、森の最初の戦闘は必ず勝て、ボス撃破は約7割、1回の遠征で平均約570Gを持ち帰る。坑道は★を上げてから挑む場所。

効果音は Web Audio で合成しています(音声ファイルなし)。スキップはいつでもでき、端末の「動きを減らす」設定では揺れと粒子を抑えます。

## テストで確かめていること

- 排出率が `tools/gacha_sim.py` のシミュレーションと一致する(SR以上33.9%、SSR以上8.36%、還元率約59%など)
- SSR以上は30パック以内、URは200パック以内に必ず出る
- 最初の5パックで SSR 以上が必ず出る
- 交換ポイントを併用すると、約110パックで全60種がそろう
- カプセルは最後まで引けば中身が全部出て、目玉までは平均約25.5回
- 戦闘の各能力(分身、盾、回復、道連れ、封印竜の★2化、商才)が仕様どおりに働き、全カードの組み合わせで必ず終わる
- 相場が上下限の中で動き、客が好みと予算に応じて買う、値切る、見送る

わざと不具合を入れて(天井を外す、盾を無視するなど)、テストが落ちることも確かめています。

## 仮置きの部分

カードの能力と数値、客の予算、相場の揺れ幅は、試作用の仮の値です。プレイテストで調整します。
カードの絵は、カードIDから作る仮のモンスター(SVG)です。本番の絵に差し替えます。
