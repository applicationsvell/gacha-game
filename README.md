# gacha-game

ガチャ(パック開封)を主役にしたゲームの企画リポジトリです。現在は試作の段階で、ゲームのロジックと自動テストまでできています。画面はまだありません。

- [企画提案書「パックモンガー」(仮題)](docs/PROPOSAL.md): 市場調査、ゲームの内容、ガチャと経済の設計、販売と開発の計画
- [試作のロジックとテスト](prototype/README.md): パック開封、天井、交換、カプセル、編成バトル、相場と客
- [`tools/gacha_sim.py`](tools/gacha_sim.py): 提案書の排出率・天井・経済バランスを検証するシミュレーション

```
python3 tools/gacha_sim.py
```
